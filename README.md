# Swajan Rajbanshi — Portfolio

Personal portfolio website built with vanilla HTML, CSS, and JavaScript.

**Live Site Link**: swajan-me.github.io

## About

A portfolio showcasing my work as a Computing graduate transitioning into QA and software testing. Built from scratch without any frameworks or libraries — just HTML, CSS, and vanilla JS.

## Features

- Full-page scroll snap sections with fade-in animations
- Fixed profile card that appears after scrolling past the home section
- Animated name intro overlay on page load
- Projects pulled from GitHub with modal popups
- Shared navbar and footer injected via JavaScript
- Responsive design across desktop, tablet, and mobile
